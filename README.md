# Denavto — статический сайт

Сделан по шаблону сайта 888: тёмная техно-стилистика, но с **оранжевым** акцентом (#ff7a1a), чтобы сайты разных сервисов не совпадали. Есть слайдер-баннеры (3 шт.: двигатели, ходовая и МКПП, климат), анимированные счётчики, косые переходы между блоками, полоса «Пн–Сб 09:00–19:00», галерея из 4 фото и появление блоков при прокрутке. Есть светлый вариант для светлой темы системы.

Данные взяты из 2ГИС (Excel): адрес (Майский переулок, 10г, боксы 1–3), три телефона, два WhatsApp, Telegram, ВКонтакте, часы работы, рейтинг 5.0 и 10 отзывов, услуги из рубрик. Цены — «по запросу».

На фото размыты госномера машин клиентов.

## Заявка
Клиент выбирает, куда отправить заявку:
- **WhatsApp** (+7 922 908-93-07) — чат откроется с готовым текстом;
- **Telegram** (+7 909 131-11-96) — текст копируется, клиент вставляет его в чат.

## Что где менять
- `js/config.js` — номера WhatsApp и Telegram, часы, на сколько дней вперёд открыта запись.
- `index.html` — тексты, услуги, контакты, фото.
- `css/style.css` — акцентный цвет: замените `#ff7a1a` и `255, 122, 26`.
- Надпись на фоне полосы с часами — атрибут `data-mark` у блока `.band`.
- `privacy.html` — реквизиты оператора (выделенные поля).
